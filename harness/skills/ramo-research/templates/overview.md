# 리서치 개요

## 목적과 범위

모델링 과제를 시작하기 전에 모은 코드, 논문, 기술 블로그, 공개 저장소의 정리본임. 주제 하나가
폴더 하나이고, 폴더의 `README.md` 가 그 주제의 문서 전부임. 모델이나 코드를 깊게 본 주제는
`모델·코드 분석`, 서비스의 흐름·운영 정책·변경 이력을 정리한 주제는 `서비스·정책 분석`, 여러
외부 사례를 나란히 놓은 주제는 `사례 비교` 로 표시함. 여기 담긴 수치는 남의
데이터에서 잰 것이라 우리 데이터의 측정을 대신하지 않음.

## 핵심 불변식

1. 주제 하나는 폴더 하나이고 문서는 그 폴더의 `README.md` 하나임: `research_doc.py check`
2. 문서 본문이 인용하는 출처 id 는 모두 `출처` 표에 있고, 표의 모든 행은 링크나 경로와 읽은 깊이를 가짐: `research_doc.py check --final`
3. 위 주제 목록은 각 README 의 frontmatter 에서 생성되며 손으로 고치지 않음: `research_doc.py index --check`
4. 이 파일은 `.gitattributes` 에서 `merge=union` 이라 두 사람이 동시에 주제를 추가해도 충돌하지 않음: `ramo-research` Step 6

`research_doc.py` 는 `.claude/skills/ramo-research/scripts/research_doc.py` 임.

## 읽는 법

주제 문서의 첫 문단과 그림부터 읽고, 의심스러운 주장은 `위치` 칸을 따라 원천 소스에서 확인할 것.
더 깊이 알고 싶은 부분은 그 주제로 `/ramo:research` 를 다시 실행해 새 주제 폴더로 남김.
`stale_after` 가 지난 주제는 다시 조사할 후보임.
